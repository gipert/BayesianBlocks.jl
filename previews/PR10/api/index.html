    BayesianBlocks.BayesianBlocks — Module
    BayesianBlocks

    Bayesian Blocks algorithm of Scargle et al. (2013), see BayesianBlocks.partition.

    source
    BayesianBlocks.partition — Method
    partition(data; logfitness=:cash, logprior=:p0, gamma=0.01, p0=0.01, progress=false)
partition(edges, counts; kwargs...)

    Return the optimal block edges for one-dimensional data, following the Bayesian Blocks algorithm of [1].

    data is a vector of observations (for instance event times or energies) or a StatsBase.Histogram of them. Binned data can also be given as the cell edges (one more than the number of cells) and the event counts in each cell. For raw observations the candidate block edges are the midpoints between neighboring distinct values, for binned data they are the bin edges.

    Keyword arguments

    • logfitness: log of the block fitness function, :cash (Cash statistic for Poisson counts)
    • logprior: log of the prior on the number of blocks, :p0 (false alarm probability p0) or :gamma (geometric prior with ratio gamma)
    • gamma, p0: parameter of the chosen prior
    • progress: display a progress bar for long computations

    The run time grows with the square of the number of distinct values or bins.

    Example

    using Distributions, StatsBase, Plots, LinearAlgebra

data = vcat(rand(Normal(0), 1000), rand(Cauchy(5), 1000))
data = data[(data .> -5) .& (data .< 10)]

h = fit(Histogram, data, -5:0.1:10)

# choose to use all data or an histogram of it!
hb = fit(Histogram, data, BayesianBlocks.partition(data))
hb = fit(Histogram, data, BayesianBlocks.partition(h))

plot(data, normalized=true, st=:stephist, nbins=1000)
plot!(normalize(hb), st=:step, w = 3)
